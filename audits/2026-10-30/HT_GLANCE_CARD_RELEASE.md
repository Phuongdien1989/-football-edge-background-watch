# HT glanceable card — approved visual concept

User approved the white/navy/blue/emerald mobile mockup, with league/match/score first, visual game outlook, three small live metrics, model probability rail, separate data/market strip, trial recommendation, Fair/EV, compact five-minute clock, collapsed details and 1–5 fixture navigation. Apply to HT first in the shared experimental app; other mechanisms preserved.

## Truthful mapping to current data

Use existing assessed HT model/quote and existing native HT evaluation. Native read bridge is detached and cached by observation ID/time, not fetched every clock tick; no provider/network request. Only matching observation and fresh stats can supply descriptive LIVE labels/windows. Reuse existing H1 labels/cutoffs (`accel >= .35`, native CORE/state and baseline/partial status); these do not create new recommendations or feed the probability model. No guessed home/away dominance: current H1 aggregate evidence cannot reliably attribute which team attacks. The card therefore says H1 rhythm/pressure rather than inventing “Arsenal pressing”. No fake pitch positions or attacking-arrow tracking.

Metric tiles display actual total SOT and xG delta from completed five-minute native windows; missing or partial windows/field presence show —. Genuine zero retained. The small chart shows SOT/minute in completed 3/5/10-minute windows, with unknown bars distinct. Without evidence it stays empty rather than copying mockup +0.38 or 2–0. Team identities use local initials, no invented official crests or remote image requests. Source league, names, phase, minute, score and freshness displayed.

Probability is the existing independent additional-goal probability; prices never manufacture LIVE pressure or a new probability. Exact-line five-state distribution, original recommendation, full five-minute session, samples and original warnings retained under one collapsed detail disclosure. A compact historical quote line keeps the ten-minute record visible, with full historical state in detail. No old reference becomes a current entry. Source fixture order retained in up to five links; no model re-ranking. Original single selected HT card/router remains; duplicate placeholder title/description hidden only where the new card exists.

## Protected logic

`assessWithSession`, storage keys, retained recommendation persistence, thresholds, model, valuation, events and timers preserved. Scope check compares pre-render UI prefix (excluding new view import) and schedule/event initialization byte-for-byte to deployed baseline. Public model, session and probability formatter assets untouched. Pure renderer tests mutation, escaping, zero/missing, stale/mismatched data and action mapping.
