Football Edge Support

Sports analytics & live match intelligence

Football Edge Store Edition provides football analytics, live signal monitoring, data-quality information and optional push notifications. It does not place bets or process financial transactions.

Common help

  • No live matches: wait for a supported live fixture or use the clearly labeled Sample Analysis when available.
  • Notifications: enable Native Push in Settings and allow notification permission in iOS.
  • Notification data deletion: use Disconnect & Delete Notification Data in the native notification controls.
  • Temporary provider issue: retry after the next scan cycle. Football Edge should show a degraded-state message rather than requiring a live provider response for every screen.

Request support

Technical support requests can be submitted through the Football Edge project issue tracker. Do not include API keys, push tokens, passwords, private keys or other secrets in a public support request.
